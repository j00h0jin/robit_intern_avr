# Day01 Task01

#### 플로팅(Floating)상태에 대해 설명하고, 플로팅 상태가 문제가 되는 이유와 이를 해결하기위한 방법을 설명하시오

---

MCU에서 플로팅(Floating)은 입력 핀이 VCC나 GND 어디에도 연결되지 않아 값이 확정되지 않은 상태(전압이 떠있는 상태)를 말한다. 플로팅 상태인 경우 주변 전기 노이즈에 따라 값이 계속해서 바뀌게 된다. 값을 읽어와서 특정한 기능을 구현하려고 할 때 전기 노이즈에 따라 값이 변화한다면 원하는 기능을 구현하기 힘들 것이다. 이러한 예시처럼 플로팅 상태에서는 오작동을 할 가능성이 크기 때문에 초기값을 지정해주어야 한다. 

일반적으로 볼 수 있는 플로팅의 예시는 스위치가 연결되지 않은 상태에서 일어나게 된다. 플로팅을 방지하려면 '값이 확정되지 않는 상태'를 '값이 확정된 상태'로 만들어주면 된다. 이때 초기값을 풀업 또는 풀다운으로 설정해주면 되는데, 초기값을 1로 설정하면 풀업(PULL UP), 0으로 설정하면 풀다운(PULL DOWN)이라고 한다.

---

하드웨어(회로)에서 풀업과 풀다운을 만들기 위해서는 저항을 적절한 위치에 배치해주면 된다. 만약 핀과 VCC 사이에 스위치가 있고, 스위치가 눌리지 않은 상태라면 현재 핀 상태는 플로팅 상태이다. 이때 저항을 GND와 연결해주게 되면 핀의 전압이 GND로 빠지면서 0V(풀다운) 상태가 된다. 반대의 상황에서도 마찬가지다. 핀과 GND 사이에 스위치가 있고, 스위치가 눌리지 않은 상태일 때, 핀은 플로팅 상태이다. 저항을 VCC와 연결해주게 된다면 5V(풀업) 상태가 되면서 플로팅 상태를 벗어날 수 있게 된다. 전기는 결국 VCC와 GND가 연결되어있어야만 흐르기 때문에 스위치 때문에 끊어져있는(고립된) 핀을 흐르게 해준다고 생각하면 이해가 쉽다.

ATmega128을 포함한 보통의 MCU에서는 내부풀업이라는 기능이 탑재되어있다. 회로에서 저항을 연결하지 않아도 내부적으로 풀업 저항이 연결되어 있어 소프트웨어적으로 상태를 지정해준다면 풀업 기능을 사용할 수 있다. ATmega128에서 풀업을 지정하려면 다음과 같이 하면 된다.

```C

DDRD = 0x00; // DDRD를 입력으로 설정함
PORTD |= (1 << PIND2) // 2번핀 자리에 비트 1을 민 다음에 OR 연산 (해당 자리가 1로 바뀌면서 풀업 지정)

```
